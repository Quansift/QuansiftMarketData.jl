# Benchmark environment

The benchmark is resolved from `Project.toml`; it intentionally has no committed
`Manifest.toml`. Julia manifests record version-specific standard-library and JLL
dependencies, so a manifest generated by the supported Julia 1.10 floor is not a
portable lock for the Julia 1.12 benchmark runner.

CI starts from a clean checkout, develops the repository package into this
environment, and runs `Pkg.resolve()` followed by `Pkg.instantiate()`. A minimal
micro benchmark is executed on both Julia 1.10 and Julia 1.12. This keeps the
declared Julia floor executable while independently verifying the current runner.

To reproduce either check locally, replace `<version>` with `1.10` or `1.12`:

```sh
julia +<version> --project=benchmark -e \
  'using Pkg; Pkg.develop(path="."); Pkg.resolve(); Pkg.instantiate()'
TIINGO_BENCH_TICKERS=1 TIINGO_BENCH_DAYS=2 TIINGO_BENCH_SAMPLES=1 \
  TIINGO_BENCH_ITERATIONS=1 TIINGO_BENCH_SINK=local \
  julia +<version> --project=benchmark benchmark/run.jl micro
```
